# 木案个人工作台

这是一个单文件 HTML 应用，通过 GitHub Pages 使用。

## 14 天实验

“14天实验”记录睡眠、清醒度 / 脑雾、回忆得分、独立思考与 AI 使用习惯；“14天英语训练”是独立计日的英语正反馈周期。总览提供两个系统的入口。

今日待办、时间规划、每日单词、四象限、秋招投递和奶茶记录已移除，包括页面、导航、相关操作与设置。旧版业务数据仅作为历史归档保留在完整 JSON 备份中；移除界面不会清空已有记录。旧功能链接会跳转到仍可用的默认页面。

- 10 词回忆：当天点击后生成随机词组，看 60 秒后自动遮盖。提交即时回忆后，等待 15 分钟再做延迟回忆；也支持亲友提供词组或纸上完成后补记。
- 独立思考：8 分钟计时、首次强烈求助冲动记录；结束后手动与 AI 回答对照。本应用不连接 AI 服务。
- 面试练习：3–5 个关键词，看 30 秒后隐藏，再脱稿说 60–90 秒。不会录音。
- D1–D6 只记录；D7 可主动保存一次阶段均值快照；D14 开放完整趋势与复盘。统计区分缺失值与 0，并显示有效样本数。这是个人观察工具，不是标准化测验或医学诊断。
- 计时以保存的时间戳恢复，切换页面或刷新不会重置。关闭页面时不发送后台通知。
- 支持多个实验周期、补记、复制简短日记录，以及包含原有业务数据的完整 JSON 备份与恢复。

应用数据保存在浏览器的 `localStorage` 中，键名为 `muan_workspace_state`。当前不支持电脑与手机之间自动同步；在更换设备或清理浏览器数据前，请先导出 JSON 备份。

## 14 天英语正反馈

- 标准版每天 30–40 分钟，40 分钟提醒收尾，45 分钟停止训练计时；离开英语页面会自动暂停。最低版为 3 分钟回测 / 熟悉、3 分钟输入、4 分钟输出（至少说 30 秒），同样算完成。
- D1–D13 内置每天 8 个实用词 / 词组、对应例句，以及 193–206 词的原创虚构短文。可在开始回测前替换词组，在记录第一遍理解前替换输入材料。
- 提取测试先显示中文，翻开英文后自行判断。第一次学习回测后，5 分钟再测一次；次日提取实际学过的昨日词组。没有昨日记录就跳过，不制造补课任务。支持记录已经在线下完成的回测。
- 输入使用 What happened? → Why? → So what?，记录两遍自估理解程度。口语分为熟悉话题、Point → Example → Result、抽题后 60 秒独立准备三个阶段；先说一遍，只改三处，再说一遍。
- 口语支持浏览器麦克风录音、回听、下载及外部音频上传；也可以明确记录外部完成的时长。录音最长 90 秒，结束后保存到当前浏览器的 IndexedDB 数据库 `muan_english_audio`。应用不上传音频、不转写、不自动评定语言能力。
- 每日保留五项反馈与一句收获：昨日 / D1 词汇回忆、今日两次词汇提取、输入理解变化、两遍口语卡顿、完成 ✅。不以必须涨分为完成条件。
- 过去日期只回看，不补课、不叠加、不设置连续打卡惩罚。D14 不学新内容，取回本周期 D1 实际保存的词组、材料、话题与录音进行对照；若 D1 缺失，会明确提示不可进行个人前后比较。
- 完整 JSON 备份包含英语文字记录和本机可读取的录音，导入后恢复。音频不在当前浏览器时，导出会提示缺失。更换设备前可另外下载重要录音；清理网站数据也会删除本机音频。
